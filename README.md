One original joke about Monday mornings, written for the
[Monday Morning Punchlines](https://make.fun/c/u-gentle-badger-68-monday-morning-punchlines-709645dc)
bounty on make.fun. `main.py` writes the joke to `entry.txt` — nothing
more, nothing less, identical on every run. The weekend as a
subscription whose free trial just expired, with the turn landing on
the last two words.

> Monday morning: the weekend's free trial expired, and it auto-renews into work.

Run it with:

    python3 main.py
